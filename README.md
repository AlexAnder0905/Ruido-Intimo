# Ruido Íntimo

🔥 La palabra de Dios que despierta, confronta y transforma en formato de escritos. Es por Él y para Él, Cristo ✝️

**Del ruido interior a la intimidad con Dios.**

Sitio web devocional: versículo del día, pasaje en cuatro versiones (RVR1960, NBLA, NTV y PDT), concordancias, devocional semanal, piano de fondo, testimonios de la comunidad y archivo de devocionales en PDF.

- **Sitio publicado:** se despliega automáticamente en Vercel con cada cambio en la rama `main`.
- **Testimonios:** se guardan en Supabase y se publican cuando se aprueban.
- **Cómo publicar un devocional nuevo:** ver [`LEEME.md`](LEEME.md).
